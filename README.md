# Portfolio de Théo Béranger

Portfolio statique HTML/CSS/JavaScript compatible GitHub Pages.

## Mise en ligne
1. Décompresser le ZIP.
2. Envoyer **le contenu** du dossier `portfolio-theo` à la racine du dépôt GitHub `ThEbRnGGMS/portfolio` (pas le dossier lui-même).
3. Remplacer les fichiers `index.html`, `style.css`, `script.js` et `CV_TheoBeranger.pdf`.
4. Dans **Settings → Pages**, choisir **Deploy from a branch**, branche **main**, dossier **/(root)** si nécessaire.
5. Ouvrir https://thebrnggms.github.io/portfolio/ après le déploiement.

## Personnalisation
- Modifier le texte dans `index.html`.
- Modifier les couleurs dans les variables CSS en haut de `style.css`.
- Remplacer l'avatar SVG par une vraie illustration personnelle si souhaité.
- Les projets présentés proviennent du CV et ne disposent pas encore de pages de détail publiques vérifiées.
- Le contact ouvre l'application de messagerie du visiteur : aucun serveur ni formulaire n'est requis.

## Interactions
Particules animées, effet de curseur, texte tapé, mode sombre mémorisé, filtres de projets, animations au scroll, barre de progression, menu mobile et copie d'e-mail. Respect de `prefers-reduced-motion`.
